# Interview practice

The [learning guide](LEARNING_GUIDE.md) contains ten technical questions and
three independent coding exercises. Work through them after reading the code.

Practice a five-minute explanation of architecture and experimental design.
Then open an actual incorrect development/stress result, state the expected
answer, inspect masks and contours, and diagnose it without AI-generated code.
Make an explained personal change in a separate experiment and preserve evidence.

CV wording in [CV.md](CV.md) reflects only currently verified contributions.
